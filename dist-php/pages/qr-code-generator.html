QR Code Generator

Choose what the QR code should do (open a link, join Wi-Fi, show text, write an email or call a number), type the details, and download it as PNG or SVG. These are static QR codes: the information is stored inside the code itself, so they work forever, offline, with no tracking and no subscription.

Style

Everything runs in your browser. Nothing you type is sent anywhere.

Static QR codes never expire

Many "free" QR code sites create dynamic codes. The code points to their server, which then redirects to your link. When the free trial ends, the code stops working, often after you've printed it on menus, flyers or packaging. This generator makes static codes: your link or text is encoded directly in the black and white squares. No server is involved, so the code can't be switched off and nobody tracks who scans it.

The trade-off is that a static code can't be edited after printing. If you might change the destination later, point the code at a page on your own website that you control.

Types of QR code

  • Link: opens a website. The most common use.
  • Wi-Fi: guests scan to join your network without typing the password. Works with the built-in camera on iPhone and Android.
  • Text: shows a message, serial number or instructions. Works offline.
  • Email: opens a new email to your address, with an optional subject.
  • Phone: offers to call the number. Include the country code, like +44 or +1.
  • WhatsApp: opens a chat with your number and a ready-typed message.
  • SMS: opens a text message to your number, useful for "text JOIN to…" campaigns.
  • Contact card (vCard): saves your name, phone, email and company to the scanner's contacts.

Error correction

QR codes contain extra data so they still scan when part of the code is dirty, damaged or covered. Higher levels survive more damage but make the code denser.

Printing tips

  • Size: at least 2 × 2 cm (0.8 inch) for scanning from 20 cm away. As a rule, make the code one tenth of the scanning distance: a poster read from 3 metres needs a 30 cm code.
  • Contrast: dark code on a light background. Inverted (light on dark) codes fail on many phones.
  • Quiet zone: keep the white border around the code. The downloads include it.
  • SVG for print: SVG is a vector format that stays perfectly sharp at any size, so printers prefer it.
  • Adding a logo: the logo covers the middle of the code, so the generator switches to the highest error correction automatically. Keep logos small and always test-scan.
  • Test before printing: scan it with two different phones.

Frequently asked questions

Do these QR codes expire?

No. They are static codes with your information stored inside the code, so they keep working forever and don’t depend on any website.

How do I make a QR code for Wi-Fi?

Choose Wi-Fi, enter the network name and password, and pick the security type (usually WPA). Guests can scan it with their phone camera to join.

Can I use these QR codes commercially?

Yes. They are free for any use, including menus, packaging, business cards and advertising.

What is the best format for printing a QR code?

SVG, because it stays sharp at any size. Use PNG at 2048 px if your printer or software doesn’t accept SVG.

Can I track how many people scan my QR code?

Not with a static code. To count scans, link the code to a page on your own website and use your website analytics.
