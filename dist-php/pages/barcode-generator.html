Barcode Generator

Choose a barcode type, type the value, and download a sharp PNG or print-ready SVG. For inventory, asset tags and shipping labels, use Code 128, which accepts any text. For products sold in shops, use EAN-13 (or UPC-A in North America) with a number registered with GS1.

Everything runs in your browser. Nothing you type is sent anywhere.

Check digits

EAN, UPC and ITF barcodes end with a check digit calculated from the other digits, so scanners can catch misreads. Type the number without it and the generator adds the correct digit. If you type the full number and the check digit is wrong, you'll see an error rather than an unscannable barcode.

Selling products in shops

You can generate an EAN-13 image for any number, but shops and marketplaces (supermarkets, Amazon and others) require the number itself to be registered to your company through GS1, the organisation that issues product numbers. Buy numbers from your national GS1 office, then use this tool to create the barcode images. For your own stock control, labels and events, use Code 128 freely; no registration is needed.

Printing barcodes that scan

  • Use SVG for print. Vector bars stay perfectly crisp at any size.
  • Keep the white margins (quiet zones) at both ends.
  • Dark bars on a light background. Black on white is safest; red bars can't be read by many laser scanners.
  • Don't squash it. Scale width and height together.
  • Test it with the Barcode Reader before printing a batch.

Private by design

Barcodes are drawn in your browser with the open-source JsBarcode library. Nothing is uploaded.

Frequently asked questions

How do I create a barcode for free?

Choose a barcode type, enter the value and download it as PNG or SVG.

Which barcode type should I use for inventory?

Code 128. It accepts letters and numbers and is read by almost every scanner.

Can I make an EAN-13 barcode for my product?

You can create the image here, but to sell in shops the number must be registered with GS1.

Do I need to calculate the check digit?

No. For EAN, UPC and ITF-14 the check digit is added automatically.

What format is best for printing?

SVG, because it stays sharp at any size.
