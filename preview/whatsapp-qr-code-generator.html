WhatsApp QR Code Generator

Enter your WhatsApp number with the country code (for example +44 7700 900123) and an optional message, then download the code. Anyone who scans it lands in a WhatsApp chat with you, with the message already typed, so customers can reach you without saving your number first.

Style

Everything runs in your browser. Nothing you type is sent anywhere.

How it works

WhatsApp supports "click to chat" links in the form https://wa.me/447700900123?text=Hello. The QR code contains that link. Scanning it opens WhatsApp (or WhatsApp Business) on the phone, starts a chat with your number and fills in the message. The customer just presses send.

Getting the number right

  • Include the country code: 44 for the UK, 1 for the US and Canada, 91 for India, 92 for Pakistan, 971 for the UAE, and so on.
  • Leave out the leading zero of local numbers: UK 07700 900123 becomes +44 7700 900123.
  • Spaces, dashes and brackets are removed automatically.
  • Test the code with your own phone before printing.

Ideas for the pre-filled message

  • Restaurants: "Hi, I'd like to book a table for…"
  • Shops: "Hi, I saw your flyer and I'm interested in…"
  • Property: "Hello, I'm interested in the flat on King Street."
  • Events: "Please add me to the event updates."

A specific message tells you where the customer found you, which helps you measure which flyers and posters work. Keep it short and friendly; the customer can still edit it before sending.

Where to put it

Shop windows, product packaging, menus, business cards, delivery bags, property boards, posters and the back of receipts. Add a short line like "Chat with us on WhatsApp" next to the code so people know what to expect.

Privacy

The code works without any third-party service: it's a direct WhatsApp link, so it never expires and no one tracks the scans. Your number is processed only in your browser while you make the code.

Frequently asked questions

How do I make a WhatsApp QR code?

Enter your WhatsApp number with the country code, add an optional message, and download the QR code.

Does it work with WhatsApp Business?

Yes. The same link format opens chats with WhatsApp Business numbers.

Why does the QR code open the wrong number?

Check the country code and remove the leading zero of your local number.

Does a WhatsApp QR code expire?

No. It is a static link that works as long as your number uses WhatsApp.

Can I change the message later?

The message is part of the code, so make a new code to change it.
